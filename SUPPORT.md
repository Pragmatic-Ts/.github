# Support

Read the affected repository's README and troubleshooting documentation first. Use its issue tracker for reproducible bugs and its documented channels for usage questions.

Include expected and actual behavior, version and a sanitized reproduction. Do not attach secrets, personal information, customer data or private logs.

This foundation's issue tracker is for company standards and templates. It does not provide a customer support SLA or promise product support. Each product defines its own support scope.

For vulnerabilities, follow [the security policy](SECURITY.md) and use a private reporting route.
