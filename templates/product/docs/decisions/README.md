# Architecture decisions

Create NNNN-short-title.md for consequential decisions, using ../.. relative paths appropriate to this repository.

Record title, status (proposed/accepted/superseded), date, owner, context, options, decision, tradeoffs, security/operations implications, validation and reversal path. Link superseding decisions; keep history. Routine choices do not need an ADR.

Copy the organization [ADR template](https://github.com/Pragmatic-Ts/.github/blob/main/templates/ADR.md) when useful.
